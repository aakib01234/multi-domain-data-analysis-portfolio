# Project 2 Academic Recommendations

1. Create attendance alerts when a student approaches 75%, followed by teacher outreach rather than automatic penalties.
2. Offer targeted tutoring for the lowest-performing subject and students below the subject pass threshold.
3. Assign personalised study plans to at-risk students and review progress every two weeks.
4. Provide supervised computer/library access where limited internet access corresponds with weaker outcomes.
5. Track intervention effectiveness using attendance change, subject improvement, pass conversion, and risk-exit rate.
