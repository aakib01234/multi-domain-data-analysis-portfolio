# Project 5 Portfolio Recommendations

1. Evaluate return together with volatility and drawdown; do not rank assets on return alone.
2. Use the correlation matrix to identify potential diversification, while recognising that correlations can change during stress.
3. Compare the equal-weight portfolio with individual assets using the same period and assumptions.
4. Add fees, taxes, slippage, dividends, realistic rebalancing, and transaction constraints before practical use.
5. Treat all findings as educational analysis of simulated data, not investment recommendations.
