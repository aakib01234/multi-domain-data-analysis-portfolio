# Project 3 Operational Recommendations

1. Use city-season heat and rainfall patterns for staffing, maintenance, and public communication planning.
2. Inspect drainage and supply readiness before months with the highest rainfall concentration.
3. Trigger heat preparedness when forecast maximum temperature approaches the analytical 40 C threshold.
4. Maintain separate local plans because aggregate portfolio averages hide major city differences.
5. Replace simulated data with verified meteorological data and official local thresholds before real-world decisions.
