# Project 4 Healthcare Recommendations

1. Review treatment outcomes within the same condition and severity group before drawing conclusions.
2. Investigate high-readmission groups using structured clinical review rather than automatic treatment changes.
3. Combine improvement, safety/readmission, stay, cost, and patient experience instead of optimising one metric.
4. Audit missingness, data definitions, coding consistency, and subgroup representation before operational use.
5. Require clinician and ethics oversight plus risk adjustment before any real-world treatment decision.
